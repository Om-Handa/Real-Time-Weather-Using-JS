# ⚡ Installation & Setup

## 1️⃣ Clone Repository

```bash
git clone https://github.com/your-username/weather-app.git
```

## 2️⃣ Open Project Folder

```bash
cd weather-app
```

## 3️⃣ Add API Key

Create a `config.js` file:

```javascript
export const API_KEY = "YOUR_API_KEY";
```

## 4️⃣ Run Project

Use VS Code Live Server or open `index.html`.
